# Политика безопасности

## Сообщение об уязвимости

Об уязвимостях сообщайте **приватно** через GitHub Security Advisories
(`Security` → `Report a vulnerability`) репозитория, **не** через публичные Issues
или Pull Requests.

Пожалуйста, приложите: затронутую версию/коммит, описание проблемы, шаги
воспроизведения и оценку влияния. Мы подтвердим получение и сообщим о ходе
устранения.

## Поддерживаемые версии

Исправления безопасности выпускаются для основной ветки (`main`). Закрепляйте
зависимость на конкретную версию и своевременно обновляйтесь.
